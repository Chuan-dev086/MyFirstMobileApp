# MyFirstMobileApp

This is my first Android app built while learning Android development with Kotlin and Jetpack Compose.

## 🚀 Features
- Add tasks to a to-do list
- Tap a task to delete it
- Snackbar notification on delete with an "Undo" option to restore the item

## 🛠️ Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose (Material 3)
- **State Management:** State, MutableStateListOf
- **Asynchronous Programming:** Coroutines
